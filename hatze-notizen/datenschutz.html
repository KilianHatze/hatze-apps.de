1. Grundsatz

Hatze Notizen ist ein Programm, das auf deinem Rechner läuft. Es gibt kein Konto, keinen Server von mir, keine Werbung, keine Nutzungsstatistik und keine Absturzberichte. Ich erhalte keine Daten über dich oder deine Notizen.

2. Deine Notizen

Notizen, Bilder, Anhänge, Zeichnungen, Versionsverlauf, Papierkorb und Backups speichert das Programm als Dateien in dem Ordner, den du selbst auswählst (dem „Vault“). Einstellungen liegen in deinem Windows-Benutzerprofil. Auf Wunsch verschlüsselt das Programm den Vault mit AES-256; das Passwort und der Wiederherstellungsschlüssel verlassen deinen Rechner nicht. Legst du den Vault in einen Cloud-Ordner wie OneDrive oder Dropbox, gelten für die Synchronisation die Bedingungen dieses Anbieters.

3. Funktionen, die eine Verbindung aufbauen

Im Auslieferungszustand baut Hatze Notizen keine Verbindung ins Internet auf. Das passiert nur in den folgenden Fällen, die du selbst auslöst:

  • Update-Prüfung: Ab Version 2.0.2 fragt das Programm beim ersten Start einmal, ob es beim Start nach neuen Versionen suchen soll. Nur wenn du zustimmst oder selbst eine Update-Quelle einträgst, ruft es dort die aktuelle Versionsnummer ab, standardmäßig aus meinem öffentlichen Verzeichnis bei GitHub. GitHub sieht dabei deine IP-Adresse; Notizinhalte werden nicht übertragen. Ändern kannst du das jederzeit unter Einstellungen → Updates.
  • KI-Helfer: Hinterlegst du einen eigenen API-Schlüssel von Anthropic, kannst du markierten Text oder die geöffnete Notiz zum Zusammenfassen, Umformulieren, Korrigieren oder Weiterschreiben an Anthropic (Anthropic PBC, USA) senden. Gesendet wird nur, was du dabei auswählst, nie der ganze Vault. Mit deinem Schlüssel lädt das Programm außerdem die Liste der verfügbaren Modelle bei Anthropic. Die Übertragung läuft direkt von deinem Rechner zu Anthropic über dein eigenes Konto dort; es gelten die Bedingungen und die Datenschutzerklärung von Anthropic. Ich erhalte davon nichts.
  • Freigabe im WLAN: Gibst du eine Notiz frei, ist sie über einen Link mit Zufallsschlüssel für Geräte in deinem lokalen Netzwerk erreichbar, bis du die Freigabe beendest. Dabei läuft nichts über einen fremden Server.
  • Bilder mit Web-Adresse: Enthält eine Notiz ein Bild, das per Web-Adresse eingebunden ist (etwa nach dem Einfügen aus einer Webseite oder dem Import aus einem Markdown-Ordner), lädt das Programm es beim Anzeigen vom jeweiligen Server. Dieser Server sieht dabei deine IP-Adresse. Bilder, die du als Datei einfügst, liegen in deinem Vault und werden nicht aus dem Netz geladen.
